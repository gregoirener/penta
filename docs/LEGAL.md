# PENTA — Ground rules

Short, because the rules are short.

## What this project is

An original console-style operating environment, built from open-source
components and code we write, that runs games we legally own on hardware we own.

## What it never contains

- Sony firmware, system software, or any file extracted from a PlayStation.
- PlayStation fonts, logos, icons, wordmarks, sounds, or UI artwork.
- Any emulation of PS5 hardware, or any attempt to run commercial PS5 titles.
- Hardware, serial, or identity spoofing of any proprietary component.
- Anything that circumvents a technical protection measure.

## Inspired vs. cloned

The PS5's **design language** — dark spatial UI, a horizontal row of large key
art cards, a blurred overlay Control Center, generous type, restrained motion —
is a set of ideas, and building your own take on it is ordinary UI work. Its
**specific assets and trade dress** — the exact icons, the wave logo, the boot
chime, the typeface, the name — are Sony's.

So: build the feel, draw your own everything. Concretely —

| Do | Don't |
|---|---|
| Original SVG icons in a consistent grid | Trace or reuse PS5 system icons |
| An open/licensed geometric sans (Sora, Manrope, Geist) | SST or any Sony typeface |
| Original short UI sounds and boot chime | Sample the PS5 startup sound |
| Your own logo and product name | The PlayStation logo or name |
| "PENTA" | "PS5", "PlayStation 5" in the product itself |

## Distribution

Keep it personal. A public repo of *code* is fine; a public repo that ships a
pixel-accurate reproduction of another company's shipping UI, under branding
that suggests it's theirs, is the thing that draws letters. If you do publish,
publish the engine and your own assets, and say plainly what it is.

## Games

Titles come from stores you bought them from (Steam, GOG, Epic), from open-
source projects, or from homebrew you or others made and chose to share. ROMs
are your business and your dumps of your own media.
